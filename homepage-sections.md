# Homepage Curated Sections

> **Edit this file anytime directly on GitHub to update the homepage storefront sections in real-time.**
>
> **How to edit:**
> - `## Section Title` — Section heading displayed on the storefront.
> - `badge: BADGE TEXT` — Visual tag (e.g. `FEATURED SPOTLIGHT`, `FRESH DROPS`, `HALL OF FAME`, `ITCH.IO EXCLUSIVES`).
> - `subtitle: Description` — Descriptive subtitle text below the heading.
> - `type: spotlight | grid` — `spotlight` creates a large featured trailer card on the left with companion cards on the right. `grid` displays a clean 4-column storefront grid.
> - `actionText: Button Label` — Label on the right action button (e.g. `Browse All Trending`, `Browse All New Releases`).
> - `actionHref: target` — Either a tab (`trending`, `latest`, `top-rated`, `upcoming`) or a catalog URL (e.g. `/games?store=itch` or `/games?tags=retro`).
> - `- game-slug` — Slugs of the games to display in this section. You can also append notes like `- resident-evil-4--1 | Resident Evil 4`.
